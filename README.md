# Pandas Practice

Репозиторий с задачами по pandas для подготовки к собеседованиям
на аналитика данных / продуктового аналитика.

## Темы

- [x] Окружение, Series, DataFrame, индексы
- [x] groupby, merge, pivot_table
- [ ] Типичные ошибки merge (дубликаты, NaN, размножение строк)
- [ ] EDA-проект

## Ноутбуки

- `01_environment_and_basics.ipynb` — создание DataFrame, выборка, loc/iloc
- `02_groupby_merge_pivot.ipynb` — groupby, merge, pivot_table
- `03_merge_errors.ipynb` — типичные ошибки при соединении
- `04_eda_project.ipynb` — полный EDA на открытых данных

## Данные

В папке `data/` — CSV-файлы, которые используются в ноутбуках.
